# List of accessible math Resources

last updated July 8, 2026

This is a start on the resources the working group plans to maintain. We welcome suggestions on what to add.


## Portable Equation Converter 

The Portable Equation Converter (PMC) parses LaTeX, Typst, and SymPy math notation to compile documents into WCAG 2.2-compliant MS Word, HTML, PDF, or Markdown formats for visually impaired users. It features automatic math-dialect translation (MathML/OMML), accessibility audits (for headers and alt text), and pre-packaged standalone binaries.
